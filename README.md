# JARVIS Command Interface

A cinematic, futuristic AI command-center website built as an original HUD-inspired interface.

## What is included

- Animated AI core
- Futuristic glassmorphism panels
- Live particle network background
- Moving grid and scanline overlays
- Mission modules
- Interactive command terminal
- Responsive mobile layout

## Files

```text
index.html
styles.css
script.js
README.md
```

## Deploy on GitHub Pages

1. Open the repository settings.
2. Go to **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch: `main`.
5. Choose folder: `/root`.
6. Save.

GitHub will publish the static site after Pages finishes deploying.

## Design note

This is an original futuristic AI/HUD interface. It is inspired by the general sci-fi command-center genre and does not copy protected Marvel/Iron Man artwork.
